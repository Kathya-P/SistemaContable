# SistemaContable

Configuración base del entorno para trabajar con **Node.js**, **React** y **Supabase**.

## Requisitos

- Node.js 22 (ver `.nvmrc`)
- npm

## Instalación

```bash
npm ci
```

## Dependencias incluidas

- `react`
- `react-dom`
- `@supabase/supabase-js`

## Variables de entorno recomendadas

Para integrar Supabase en el proyecto, define:

- `SUPABASE_URL`
- `SUPABASE_ANON_KEY`

> No subas claves reales al repositorio.
